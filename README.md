# Team 10416, Radical Raccoons, FRC Robot Code 2026

This repository contains the code for Team 10416’s 2026 FRC robot for the 2026 season, Rebuilt. 
The robot code is written in Java and is based on the YAGSL (Yet Another Generic Swerve Library) example, which we are using as a starting point for this season's robot code.
Updates and changes will continue to be made as development continues.
